## Задание 1. Функции и ссылки

Прогнозы до первого запуска отдельно не сохранились. Ниже приведены фактические результаты и объяснения.

### 1. Параметры и возвращаемое значение

Фактический вывод: 5 и 23.

При числовых аргументах выполняется сложение. Если один аргумент — строка, оператор + объединяет текст. Поэтому результаты — число 5 и строка "23".

### 2. Тело стрелочной функции

До исправления square(4) возвращала undefined.

Причина — отсутствие return в теле функции. После добавления return результат стал 16.

### 3. Два имени одного объекта

Фактический вывод: 5 и true.

Присваивание объекта другой переменной не создаёт копию. Обе переменные указывают на один объект. Поэтому изменение через одну переменную видно через другую.

### 4. Копия массива с объектом

Фактический вывод: 7, false, true.

Spread создаёт новый массив, но объект внутри остаётся общим. Поэтому массивы разные, а вложенный объект один и тот же. Изменение объекта через копию отражается в исходном массиве.

### 5. Копия объекта и порядок свойств

Фактический вывод: 3 8 3 и false.

При повторении свойства используется последнее значение. Порядок spread и нового значения влияет на результат. Новый объект отличается от исходного.

### 6. Параметр по умолчанию

Фактический вывод:

```text
Без названия
Без названия
null

```

Последний результат — пустая строка.

Значение по умолчанию применяется, если аргумент не передан или равен undefined. Для null и пустой строки оно не применяется.

## Задание 2. Создание задачи

Задача содержит четыре поля:

- id — положительное безопасное целое число;
- title — строка длиной от 1 до 100 после удаления пробелов по краям;
- completed — логическое значение;
- priority — low, medium или high.

Функция createTask проверяет данные и создаёт новую задачу.

При успехе возвращается объект с ok: true и полем task. При ошибке возвращается ok: false и описание причины.

Новая задача всегда имеет completed: false. Приоритет по умолчанию — medium.

Проверены правильные данные, граничные длины названия, пробелы по краям, неверные типы, номера и приоритеты.

Два вызова createTask создают разные объекты. Изменение одной задачи не меняет другую.

## Задание 3. Чтение списка

Реализованы четыре функции:

- findTaskById — поиск задачи по id через find;
- getPendingTasks — отбор невыполненных задач через filter;
- getTaskTitles — получение названий через map;
- getTaskStats — расчёт сводки.

Для общего набора невыполненные задачи имеют номера 4 и 7.

Поиск отсутствующего номера 777, строкового номера "4" и поиск в пустом массиве возвращают undefined.

Сводка общего набора:

```text
Всего: 4
Выполнено: 2
Осталось: 2
Прогресс: 50.0%
```

Для пустого списка все поля сводки равны нулю. При выводе появляется сообщение «Задач пока нет».

Процент возвращается числом без округления. Один знак после точки задаётся только при выводе через toFixed(1).

## Задание 4. Изменение задач

Реализованы четыре функции:

- addTask — добавление задачи в конец списка;
- setTaskCompleted — изменение статуса;
- renameTask — изменение названия;
- removeTask — удаление по id.

Операции возвращают новый массив. При изменении статуса или названия создаётся новый объект выбранной задачи.

Исходный массив и его объекты не изменяются. При отказе текущее состояние сохраняется.
