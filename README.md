## 7. Задание 3. Прогресс выполнения задач

В файле `progress.js` программа получает общее количество задач и число выполненных задач.

Сначала проверяются входные данные:

- значения должны быть целыми числами;
- общее количество должно быть от 0 до 1000;
- выполненное количество не должно быть отрицательным или превышать общее;
- строки автоматически не преобразуются в числа.

Если данные неверные, выводится одно сообщение об ошибке. Если задач нет, выводится «Задач пока нет», а процент не рассчитывается.

- ни одна задача не выполнена — «Не начато»;
- выполнена часть задач — «В работе»;

## 9. Задание 5. Отладка

В исходной программе были две логические ошибки. Программа запускалась, но давала неправильный результат:

```text
Выполнено: 32
Осталось: -24
Контрольная сумма: 6
```

### Ошибка 1. Сложение строк

- Что получилось: выполнено 32, осталось -24.
- Причина: оператор `+` объединил строки `"3"` и `"2"`.
- Исправление: преобразование строк в числа через `Number()`.
- Ожидается после исправления: выполнено 5, осталось 3.
- Фактически после исправления: [заполнить].

### Ошибка 2. Граница цикла

- Что получилось: контрольная сумма 6.
- Причина: условие `taskNumber < 4` не включало число 4.
- Исправление: условие заменено на `taskNumber <= 4`.
- Ожидается после исправления: контрольная сумма 10.
- Фактически после исправления: [заполнить].

Правильный результат программы:

```text

Осталось: 3
```
